# Proyecto: tablero de análisis e-commerce de comportamiento
En este proyecto se utilizó y organizó una base de datos (de Kaggle) usando MySQL para crear un tablero de analisis en PowerBi.
### Carpeta Base de Datos
Se puede encontrar la base de datos de Kaggle en formato CSV. Se tiene un archivo de queries con el que se corrigen varios aspectos de la base de datos, se pasa de CSV a SQL. La base de datos final es el archivo llamado "retail_store_data".
### Carpeta Documentación
En esta se encontrará el estudio de la base de datos, y las correcciones hechas. Además, se encuentra las instrucciones de uso para obtener la base de datos final a partir del archivo inicial CSV.
