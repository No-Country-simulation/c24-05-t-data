# Proyecto: tablero de análisis e-commerce de comportamiento
En este proyecto se utilizó y organizó una base de datos (de Kaggle) usando MySQL para crear un tablero de analisis en PowerBi.
### Carpeta Base de Datos
Se puede encontrar la base de datos de Kaggle en formato CSV. Se tiene un archivo de queries con el que se corrigen varios aspectos de la base de datos: se crean nuevas tablas y se reestructura la base de datos a traves de un modelo E-R y se pasa el archivo CSV a SQL. La base de datos final es el archivo llamado "retail_store_data".
### Carpeta Documentación
En esta se encontrará el estudio de la base de datos, y las correcciones hechas. Además, se encuentra las instrucciones de uso para obtener la base de datos final a partir del archivo inicial CSV.
### Tablero PowerBi 
Con el tablero de PowerBi se pueden obtener información sobre el estado del comercio usando las distintas graficas y metricas visibles, además se tienen varios filtros con los que segmentar los datos. Entre los hallazgos importantes que se pueden hacer tenemos: 
- Las zonas que generan más ingresos son Estados Unidos, seguido de Inglaterra.
- Los departamentos de la tienda que generan más ingresos son los de electronica, abasto, ropa y
- El comercio tiene mayoritariamente clientes de genero masculino entre 18-30 años.
